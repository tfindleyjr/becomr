# BECOMR Changelog

## v0.4 — Dynamic Insignia
- Replaced the static Compass Tree presentation with a layered SVG progression system.
- The full approved emblem is now a faint future-state blueprint instead of the active skill map.
- Each of the eight paths owns a distinct physical branch/region of the tree.
- Added five visual progression states: Sealed, Open, Inscribed, Ornamented, Mastered.
- Selected paths now illuminate their actual tree region while unrelated branches recede.
- Added path-specific detail motifs: circuitry, rhythm, framing, stitch, orbit, ledger, force, and truth-star markings.
- Added independent emphasis for sun, moon, compass, trunk, and roots.
- Added a five-stage visual progression explainer beneath the selected path.
- Added “Next Inscription” messaging tying the next proven node to the next earned visual fragment.
- Added initial constellation-layer architecture for future cross-tree capabilities.
- Replaced generic typography with Cinzel, Cormorant Garamond, and Manrope.
- Updated COMMAND and BUILD to use the dynamic insignia instead of a static image.
